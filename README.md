# FruitGuys
'서울 IT 아카데미 홍대' 팀 프로젝트 입니다.

## 📖프로젝트 소개
Fall Guys를 모티브로 제작한 3D 멀티플레이 캐주얼 게임입니다. 
최대 16명의 플레이어가 네트워크를 통해 동일한 스테이지에 접속하여, 
장애물을 피하고 골인 지점을 향해 경쟁하며 순위에 따라 승패가 결정됩니다.

## 🎮주요 기능
Photon Network를 기반으로 실시간 멀티플레이 환경을 구현했으며,
개별 캐릭터 커스터마이징, 상점 및 아이템 시스템, 순위 판단 로직, 랭크 시스템 등 다양한 기능들이 있습니다.
